# 设计笔记：方向 × 三层

日期：2026-10-05 · 参照技能：`frontend-design`（已装到 `~/.tnega/skills/frontend-design`）

## 简报

- 产品：XJTUCSLG 101 —— 西交大学生开源社区（非官方）的教学站。
- 读者：大二到大四的 CS / 软工学生。已经会写代码，但课堂没教过工程开发那一侧。
- 任务：让人一眼看到「工程开发到底包含哪些方向、每个方向讲到哪一层了」，并且知道下一篇该读什么、缺的那格可以由自己来写。
- 内容结构（本次改版的核心）：**方向**（env / git / github / 编辑器 / 后端 / 前端 / 数据库 / 部署 / 测试 / Agent / 基础 / 硬件 / 学习方法）× **三层**（概念 → 实践 → 贯通）。三层是真序列，所以允许编号。

## 令牌

**色（冷调印刷，一色强调）**

| 名称 | 值 | 用途 |
| --- | --- | --- |
| ink | `#16181A` | 正文、标题 |
| ink-2 | `#3A4247` | 次级正文 |
| muted | `#69737A` | 元信息、说明 |
| paper | `#F0F1F2` | 页面底色（冷灰，不是暖米色） |
| sheet | `#FFFFFF` | 纸面（表格、卡片） |
| rule | `#D3D6D8` / `#B9BEC1` | 分隔线 / 强分隔线 |
| accent | `#0E5B43` | 唯一的彩色：链接、当前态、强调 |
| code | `#1B2024` | 代码块底色 |

**字**

- 界面与标题：中文黑体栈（PingFang SC / Microsoft YaHei / Source Han Sans SC / Noto Sans SC），字重 600–700，紧字距。
- 正文（讲义体）：中文宋体栈（Source Han Serif SC / Songti SC / SimSun），17px / 1.9，行长约 34 字。
- 代码与命令：等宽栈（JetBrains Mono / SF Mono / Menlo / Consolas），只用在真正的代码上。
- 不做外部字体加载：jsDelivr 在浏览器端不可靠，Google Fonts 在国内访问不稳定，本站保持零外部依赖。

**版式**

- 首页即目录：满宽表格（方向 × 三层），格子里是已有笔记的链接，灰色的是「想写」。
- 无阴影、无圆角卡片堆；用 1px 细线分栏，交互态用左边缘 2px 强调条。
- 单色 + 一色强调，三层不靠颜色区分（列顺序本身就是序列）。

## 拒绝过的方案（都是「生成味」的默认值）

1. 现在的样子：暖米色 #f8f3e9 + 陶土色 #dd6e42 + 衬线大标题 —— 与「AI 生成设计」的第一号特征重合。
2. 深色终端风：近黑底 + 荧光绿，第二号特征。
3. 报纸式：密集多栏 + 零圆角 + 满屏细线，第三号特征。
4. SaaS 卡片套件：统一圆角 + 统一柔和投影 + 渐变洗色，第四号特征。
5. 模板装饰：全大写眉标、`A · B · C` 点分隔元信息、小号等宽数据标签、链接尾部 `→`，第五号特征。本次全部去掉（含 hover 位移与箭头滑动）。
